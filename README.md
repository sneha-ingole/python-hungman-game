# python-hungman-game
My Python Hungman Project

A simple and interactive Hangman Game built using Python.
This project allows users to guess words based on different difficulty levels and categories while tracking score and remaining attempts.


Features ✨

•Multiple difficulty levels:
  Easy
  Medium
  Hard
•Different word categories
•ASCII Hangman visuals
•Score tracking system
•Input validation
•Interactive command-line gameplay

Technologies Used 🛠️

•Python
•Jupyter Notebook

Project Structure 📂
•Hungman Project(Sneha ingole).ipynb → Main game notebook

How to Run ▶️
1.Clone the repository:
git clone https://github.com/your-username/hangman-game.git

2.Open the project folder:
cd hangman-game

3.Run the notebook using Jupyter Notebook or Jupyter Lab.


Gameplay 🎯

1.Choose a difficulty level.
2.Select a category.
3.Guess letters one by one.
4.Correct guesses reveal the word.
5.Wrong guesses reduce attempts.
6.Win by guessing the complete word before attempts run out.


Example 📸

Word: _ _ _ _ _
Attempts left: 5
Guessed letters: a, e
Score: 10
